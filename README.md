# SkylerNodes Fully Automatic Installer

This ZIP contains an independent, SkylerNodes-branded installer for the official Pterodactyl Panel and Wings.

## One-command GitHub usage

Upload `install.sh` to your GitHub repository, then run:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/YOUR_USERNAME/YOUR_REPOSITORY/main/install.sh)
```

## Menu

```text
[1] Install Panel
[2] Install Wings
[3] All-in-One
[4] Update Panel
[5] SSL / Let's Encrypt
[6] Repair / Optimize
[7] Status
[8] View Logs
[9] Backup
[10] Uninstall
[0] Exit
```

## Automation

The installer automatically handles packages, PHP, Composer, MariaDB, Redis, Nginx, Panel files,
database setup, migrations, queue worker, cron, Docker, Wings, systemd services, SSL and backups.

### Important security boundary

Wings requires a node-specific configuration containing credentials generated by the Pterodactyl
Panel. The installer deliberately does not fabricate or hard-code those credentials. Once
`/etc/pterodactyl/config.yml` exists, the installer can start Wings automatically.

The first Panel administrator is also created deliberately through Pterodactyl's administrator
command rather than putting a password into the installer.

## Supported OS

Ubuntu 22.04 and Ubuntu 24.04.

## Warning

Run this on a fresh VPS first. It changes system packages, Nginx, MariaDB, Redis, PHP, Docker,
services and firewall/network configuration. Keep `/root/skylernodes-backups` private.

This project is not affiliated with Pterodactyl or Nobita Cloud.


## Professional terminal UI

The installer uses a white-terminal-friendly blue SkylerNodes theme, boxed menus,
system information, and animated-style progress bars such as:

```text
  Installing PHP dependencies      [████████████████████████████] 100% ✓
  Running migrations               [████████████████████████████] 100% ✓
  Configuring Nginx                [████████████████████████████] 100% ✓
```

ANSI colors are used so Termius can render the branding according to its terminal theme.
